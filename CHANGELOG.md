# Changelog

## 1.3
- One-line install from GitHub, then use `simpodl` from any terminal.
- `simpodl` with no link asks for the folder first, then the link.
- New `simpodl update`: gets the newest version from GitHub. A notice appears when an update is available.
- New `simpodl uninstall`.

## 1.2
- Works from the command line: `simpodl "<link>"` and `simpodl "<link>" "D:\Data"`.
- `simpodl resume`, `simpodl help` and `simpodl version`.

## 1.1
- Windows version in PowerShell, so Python is not needed.

## 1.0
- First version: resumes after network drops, stalls and power cuts, and checks the Zenodo MD5.
